# Política de segurança

## Versões suportadas

A versão mais recente da branch principal recebe correções de segurança.

## Relato responsável

Não publique vulnerabilidades exploráveis em uma issue aberta. Entre em contato de forma privada com o mantenedor pelo recurso de relato de segurança do GitHub.

Inclua uma descrição do impacto, passos mínimos para reprodução e, se possível, uma sugestão de correção. Evite anexar documentos judiciais ou outros dados pessoais.

## Escopo

São especialmente relevantes:

- escrita de arquivos fora do diretório configurado;
- substituição indevida de arquivos locais;
- execução de conteúdo recebido da rede;
- exposição de dados ou caminhos pessoais;
- desativação ou contorno da verificação HTTPS.
